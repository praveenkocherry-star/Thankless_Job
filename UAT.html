Before you start

How to sign in
  • There are no ready-made customer accounts. Create your own: press Sign in at the top right, then the Sign up link under the Login ID box. Use your first and last name and an email, a mobile number or both.
  • To sign in later, type that email or mobile number. There is no password and, in the prototype, no code.
  • Google and Facebook buttons are shown but do not work yet.
  • Back office: press Sign in at the top right, choose the Admin tab and type the code 123456. Send OTP does not send anything yet.

A busier shop and a fresh start
  • The shop starts empty. For sample customers, orders and reviews, go to the back office, Settings, Backup and sample data, and press Load sample data. Sample customers cannot sign in.
  • To start over, use Start again with an empty shop on the same page.
  • Everything is stored in the browser you test in. A different browser or device starts with its own empty shop.
